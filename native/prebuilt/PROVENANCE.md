## Verification (per build)

- Rust guard tests (raw-ABI validation: empty groups, profit-sum
  and window overflow guards) run before every build.
- Host-matching runners run the Bun 500-problem differential
  (value/weight/choiceIndex/cellsVisited) against the FRESH
  artifact via KNAPSACK_NATIVE_DYLIB.
- The verify job checks every committed binary byte-for-byte
  against the fresh build and the source-hash above.
- rc conventions: 0 ok; −1 over budget; −2 infeasible; −3 invalid
  input; −4 contained panic (catch_unwind at the FFI edge).
